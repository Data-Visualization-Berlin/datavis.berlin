  Over the last years D3.js has become the de-facto standard for datavis on the web. While D3 is an amazing framework, it has technical limitations and it may enforce specific aproaches and aesthetic constraints. It is time to look at some other tools or see how we can use D3’s modularity to combine it with other frameworks.

  Cables.gl

  https://secure.meetupstatic.com/photos/event/b/7/3/7/600_466846903.jpeg

  Thomas Kombüchen (https://twitter.com/pandrr)

  cables (https://cables.gl/) is a visual web-based WebGL editor to create interactive experiences. With an easy to navigate interface and results in real time, it allows for fast prototyping and prompt adjustments. cables features a big library of code-blocks, so called operators for graphics, interaction and sound. Advanced users can also create their own operators by writing JavaScript code.

  cables is being developed by the Berlin based design & development studio undev (https://undev.studio/).

  Data Visualization with React

  https://secure.meetupstatic.com/photos/event/d/0/2/7/600_466733287.jpeg

  Steffen Hänsch (http://www.steffenhaensch.de/) will shed some light on the development part of interactive data visualization by walking us step by step through the creation of a Strip Plot Series with React.js. Along the way he will point out the benefits of componentization, reusability of components and the rich React ecosystem.

  Steffen is a freelance Data Visualist and Frontend Engineer motivated to create not only beautiful visualizations, but also quality software.
